# Developer Wall

Developer Wall is a simple Aperture Partners GitHub workshop. Add one profile file. Ask a partner to review it. Merge it. Then see your card on the live site.

**Live site** https://aperture-partners.github.io/developer-wall/

## Add yourself

Follow [WORKSHOP.md](WORKSHOP.md). You only need a browser.

`branch → profile → commit → pull request → review → merge → live site`

Create only `_data/profiles/YOUR-GITHUB-USERNAME.json`

```json
{
  "name": "Your name or nickname",
  "github": "your-github-username",
  "favorite_language": "Still learning!",
  "project_idea": "A delightfully useful project idea",
  "fun_fact": "Ask me later!"
}
```

One person gets one file. Do not edit another profile during the workshop.

- [Contribution rules](CONTRIBUTING.md)

This repository and site are public. Add only information you are comfortable publishing. A nickname is welcome. Do not include private details.
